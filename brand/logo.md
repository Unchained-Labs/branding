# The mark

**A fan-out.** One node on the left, three edges, three nodes on the right.

<img src="../assets/logo/png/mark-accent-128.png" width="96" alt="The Unchained Labs mark">

## What it means

The thesis of every tool in this org is one sentence: *linear execution is a
chain; the work is actually a graph.* A chain does one thing at a time and its
wall clock is the sum of every step. A fan-out does independent work at once and
its wall clock is the slowest path.

So the mark is not a broken chain link — that would only say what we are *not*.
It is the shape that replaces it: the `scope → fan out` step that opens every
graph in the reference architecture. Read left to right it is a decomposition.
Read as a glyph it is a `<`, which is where an argument opens.

"Unchained" is then a description of the shape rather than a label stuck on it.

## Construction

The geometry is computed, not eyeballed —
[`tools/mkmark.py`](../tools/mkmark.py) is the source, the SVGs are output.

On a 32×32 grid:

| Element | Position | Radius |
| :--- | :--- | ---: |
| Scope node | `7, 16` | `3.4` |
| Fan node, upper | `25, 6.5` | `2.6` |
| Fan node, middle | `25, 16` | `2.6` |
| Fan node, lower | `25, 25.5` | `2.6` |

Edge stroke is `2.1` with round caps. **Edge endpoints sit on each node's
circumference, not at its centre** — the script solves for the tangent point, so
no stroke pokes out the far side of a node at any size. Doing this by hand is
where hand-drawn graph marks come apart when you scale them down.

The scope node is deliberately larger than the fan nodes. It carries the
asymmetry that makes the mark directional: the eye starts at the heavy end.

## Files

| File | Ink | Use |
| :--- | :--- | :--- |
| `mark-accent.svg` | Chain Teal | Default. Dark or light ground. |
| `mark-paper.svg` | `#E8EDF2` | On an accent or photographic fill. |
| `mark-dark.svg` | `#0F1419` | On a light ground where teal is too quiet. |
| `mark-mono.svg` | `currentColor` | Inherits. For inline SVG in prose. |
| `favicon.svg` | Teal on navy, `rx=7` | Browser tabs — a tile, not a floating glyph. |
| `lockup-horizontal.svg` | Teal mark, paper text | Primary lockup. |
| `lockup-horizontal-dark.svg` | Teal mark, ink text | Light-ground lockup. |
| `lockup-horizontal-mono.svg` | `currentColor` | Single-ink contexts. |
| `lockup-stacked.svg` | Teal mark, paper text | Narrow spaces, avatars, tall cards. |
| `lockup-stacked-dark.svg` | Teal mark, ink text | Light-ground stacked. |

PNGs under [`../assets/logo/png/`](../assets/logo/png/) are generated by
`make png` and safe to delete. `mark-mono` is rasterised as
`mark-mono-black-*` and `mark-mono-white-*` — a PNG cannot inherit a colour, so
rendering `currentColor` as-is would silently produce black and throw away half
the reason the mono file exists.

## Sizing

**16px is the documented minimum for the mark.** At that size the `2.1` stroke
lands on roughly one pixel; below it the three edges start to merge and the
fan-out stops being legible. Use the favicon variant at 16 and 32 — the rounded
navy tile gives the glyph a defined edge that a bare mark on a browser's grey
chrome does not have.

**The horizontal lockup has a minimum of 120px wide** (about 13px cap height on
the wordmark). Below that, set the mark alone. The stacked lockup's minimum is
88px wide.

## Clear space

Keep clear space of **one fan-node diameter** — `5.2` units on the 32-unit grid,
or about 16% of the mark's height — on all sides. Nothing crosses it, including
the edge of a card.

The mark's own bounding box already has visual air on the left of the scope node;
do not compensate by tightening the left side, or a row of logos will look
mis-kerned.

## Misuse

Do not:

- **Recolour it outside the palette.** The four provided inks are the whole set.
- **Add a fourth fan node**, or remove one. Three is the reference fan-out width
  in the architecture and the count is part of the meaning.
- **Rotate it.** The left-to-right reading is the mark; vertical it is a caret.
- **Put it on a busy photograph** without the paper variant on a scrim.
- **Add a glow, gradient, or drop shadow.** Teal glow reads as a status
  indicator, which collides with the status axis in
  [`palette.md`](palette.md).
- **Set the wordmark in another face**, or re-type it as live text next to the
  mark. Use the lockup files; they carry outlines for a reason.
- **Stretch either lockup.** Scale by height and let the width follow.

## Reproducing everything

```sh
make wordmark   # Space Grotesk 700 -> outline paths
make logo       # geometry + wordmark -> every SVG
make png        # SVG -> PNG at every documented size
make verify     # asserts the PNGs are the sizes and inks they claim
```
